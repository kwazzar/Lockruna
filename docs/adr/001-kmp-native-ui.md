# ADR-001: KMP-ядро + нативний UI

- **Статус:** прийнято
- **Дата:** 2026-11-07
- **Пов'язані:** ADR-002, ADR-005

## Контекст

Вакансія вимагає досвіду з Kotlin/Swift та одним із KMP, React Native або Flutter. Автор добре знає Swift, Kotlin знає слабше. Платформи: лише iOS і Android.

## Рішення

Уся логіка (domain, application, data, presentation) живе в KMP-модулях `shared/`. Платформні відмінності (крипто-реалізації, Keychain/Keystore, біометрія, clipboard, планувальники) оформлені як порти з реалізаціями в `expect/actual` або в нативних застосунках. UI нативний: SwiftUI на iOS, Jetpack Compose на Android. Структура модулів описана в ADR-005.

## Наслідки

- (+) DRY: один набір бізнес-логіки й один набір тестів.
- (+) Нативні API безпеки (Keychain/Keystore, біометрія) без обгорток крос-платформного UI.
- (−) Складніша збірка (Gradle + Xcode), на налаштування потрібен приблизно тиждень.
- (−) Автор слабше знає Kotlin, тож крива навчання крутіша.

## Альтернативи

- **Native ×2** (Swift + Kotlin): логіка й тести двічі.
- **Flutter / React Native:** втрата прямого доступу до нативних API безпеки та нативного UI.
